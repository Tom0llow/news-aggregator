# Repository Skills

This repository provides focused Codex workflows under `.agents/skills/`.

Available skills:

| Skill | Use |
| --- | --- |
| `implement-feature` | New functionality or intentional behavior changes |
| `fix-bug` | Reproduce, diagnose, regression-test, and fix incorrect behavior |
| `code-review` | Read-only defect-first review of diffs/branches/commits/PRs |

Codex may select a skill implicitly from its description, or it can be invoked explicitly from the Codex IDE/CLI.

Keep skills focused. If a workflow becomes materially different, prefer a separate skill rather than turning one skill into a catch-all process.
